# Deep Learning Biomarker Discovery with Bidirectional Validation

## Project Overview
Comparing deep learning models with penalized Cox regression for biomarker discovery using TCGA and ORIEN cohorts.

## Project Structure
```
project/
├── src/           # Source code
├── config/        # Configuration files
├── notebooks/     # Jupyter notebooks for exploration
├── scripts/       # Training and evaluation scripts
├── tests/         # Unit tests
├── results/       # Results (gitignored)
├── figures/       # Figures (gitignored)
└── logs/          # Logs (gitignored)
```

## Setup
```bash
# Create environment
conda env create -f environment.yml

# Activate environment
conda activate biomarker-dl
```
